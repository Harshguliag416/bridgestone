# 🌐 Bridgerton International Pvt Ltd

The official web portal for **Bridgerton International Pvt Ltd**, a premier global shipping, drayage, and freight forwarding coordination provider based in Mohali, Punjab.

---

## 🚚 Key Services Represented

* **Drayage & Port Logistics**: Real-time container handling and port-to-port logistics management.
* **Global Freight Forwarding**: Coordinating Full Truckload (FTL) and Less Than Truckload (LTL) shipments across domestic and international lanes.
* **Outsourcing & Back-Office**: Back-office support systems optimized for USA-based shipping lanes and logistics firms.
* **Interactive Route Map**: Beautiful custom-designed world maps illustrating supply chain corridors.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, Vanilla CSS3 (CSS Variables, Flexbox, CSS Grid)
* **Animations**: Animate On Scroll (AOS) library, CSS keyframes for dynamic path routing
* **Icons & Assets**: FontAwesome icons, GeoJSON custom maps

## ⚙️ How to Run Locally

Since the site consists of standard HTML, CSS, and JS, you can run it directly:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Harshguliag416/bridgestone.git
   ```
2. **Open index.html**:
   Double click the `index.html` file or run it using a local development server (such as Live Server in VS Code):
   ```bash
   # If you have node installed
   npx serve .
   ```
